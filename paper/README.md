# Paper — COMPLEX NETWORKS 2026 extended abstract

**Track:** extended abstract (recommended 2–3 pages, hard max 4 — we are at 4).
**Format:** Springer LLNCS (official CNA abstract template; `llncs.cls` +
`splncs03.bst` vendored here). **Submission:** Microsoft CMT
(https://cmt3.research.microsoft.com/COMPLEXNETWORKS2026), deadline
**2026-09-02 AoE**; notification 2026-10-01; camera-ready 2026-10-08.
Single-blind. Accepted abstracts appear in the Book of Abstracts.

## Build

```bash
tectonic main.tex        # or any LaTeX engine; tectonic needs no TeX install
```

The paper figure (`../figures/exp1_crossover.png`) is generated by
`python experiments/cp1_analysis.py` (pure re-analysis of the versioned
paired CSVs — no simulation); legacy notebook figures regenerate via
`python figures/make_all.py`. There are no hand-made plots; the
synthetic-data stamp is baked into every figure.

## Number provenance (anti-narrative-drift contract)

Every statistic in `main.tex` derives from `numbers.json`, produced by
`python paper/extract_numbers.py` from the versioned result CSVs in
`experiments/results/` under the D19 source policy (PAIRED n=50 results for
every seeded-strategy mean/contrast; the independent panel only for broadcast
and the p_innov=0 ablation), and is enforced by `python paper/audit_numbers.py`
(42 claims; CI-gating). CP3 corrigenda: decisions.md D23. Oral-defense map:
`REVIEWER_RATIONALE.md` (v3).
