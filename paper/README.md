# Paper — COMPLEX NETWORKS 2026 extended abstract

**Track:** extended abstract (recommended 2–3 pages, hard max 4 — we are at 4).
**Format:** Springer LLNCS (official CNA abstract template; `llncs.cls` +
`splncs03.bst` vendored here). **Submission:** Microsoft CMT
(https://cmt3.research.microsoft.com/COMPLEXNETWORKS2026), deadline
**2026-09-02 AoE**; notification 2026-10-01; camera-ready 2026-10-08.
Single-blind. Accepted abstracts appear in the Book of Abstracts.

## Build

```bash
tectonic main.tex        # or any LaTeX engine; tectonic needs no TeX install
```

Figures are referenced from `../figures/` and regenerated by
`python figures/make_all.py` — there are no hand-made plots. The
`trim=...` options in `\includegraphics` crop only the figures' internal
title bands (duplicated by the LaTeX captions); the synthetic-data stamps at
the bottom of each figure are preserved.

## Number provenance (anti-narrative-drift contract)

Every statistic in `main.tex` derives from `numbers.json`, which is produced
by `python paper/extract_numbers.py` from the versioned result CSVs in
`experiments/results/` (50-replicate headline; 12-replicate sweeps). To audit:
re-run the extractor and grep the text. `REVIEW_B.md` (repo root) maps every
claim to its notebook evidence.

## Checklist before submission (human steps)

- [ ] CMT account; primary + up to 4 secondary subject areas; ≥3 keywords.
- [ ] Upload the PDF as a file (abstract field is not used for this track).
- [ ] Final read of REVIEW_B.md §"weakest points" — these are the referee
      conversations to prepare for.
